# 目标参考尺度标定记录（2026-09-13）

## 目的与冻结配置

本次标定用于 `global_state_v3 + coupled + legacy` 正式主实现，在启动新一轮长实验
之前消除旧 `requires_recalibration_after_global_state_v3` 标识。它只更新
$G_1$ 三项的参考尺度，不改变加权完成时延惩罚的定义或算法结构。

- 环境种子：`42, 123, 456, 789, 1024`；
- 每个种子：200 帧；
- 策略状态：未调用训练更新；
- 队列/时延尺度：每个种子的绝对值中位数，再取跨种子中位数；
- 能量尺度：仅在非零活跃帧使用同一规则；
- 更新规则：旧尺度与直接观测尺度在对数空间取 0.5 阻尼。

运行命令：

```bash
PYTHON_BIN=/home/hp/miniconda3/envs/sagin/bin/python \
  scripts/ldactl calibrate \
  --frames 200 \
  --seeds 42,123,456,789,1024 \
  --workers 5
```

`--workers 5` 只把相互独立的种子分配到不同进程；每个种子的随机初始化、任务流
和逐帧计算路径与单进程版本相同，汇总顺序按输入种子固定。

## 观测结果

| 种子 | $|G_Q|$ 中位数 | $|G_D|$ 中位数 | $|G_E|$ 非零中位数 |
| ---: | ---: | ---: | ---: |
| 42 | 715,920 | 13.074 | 65,101 |
| 123 | 757,320 | 13.507 | 66,881 |
| 456 | 651,380 | 13.058 | 52,250 |
| 789 | 595,850 | 12.368 | 54,579 |
| 1024 | 721,660 | 13.320 | 57,046 |

能量漂移项在 1000 帧中的非零比例为 98.5%。跨种子直接观测尺度为：

$$
Q_{\mathrm{obs}}=715921,\qquad
D_{\mathrm{obs}}=13.0736,\qquad
E_{\mathrm{obs}}=57046.5.
$$

相对于旧尺度 $(1072550, 13.5161, 23515.5)$，对数阻尼后采用：

$$
Q_{\mathrm{ref}}=876277,\qquad
D_{\mathrm{ref}}=13.2930,\qquad
E_{\mathrm{ref}}=36626.2.
$$

使用直接观测尺度做归一化诊断时，三项绝对贡献的平均占比为：队列 31.6%、
时延 35.3%、能量 33.1%。这表明三项处于可比较量级，但不意味着三个权重具有
相同理论重要性，也不是收敛或正式性能结论。
